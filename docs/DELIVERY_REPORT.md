# VideoManager 0.1.0 交付与验收记录

日期：2026-09-18。需求基线：本目录 `PRD.md`、`TRD.md`。交付为可安装、可直接运行的 Windows x64 开发验收版本；源码、原生组件、构建脚本、测试与安装包一并提供。

## 功能落地

| 需求 | 实现与验证 |
| --- | --- |
| FR-01 资源与索引 | 根目录添加/合并、分页扫描、文件监听与定期补扫、暂停/取消、离线保留、稳定身份；实际十万文件三轮索引 |
| FR-02 分区展示 | 直属文件夹/媒体分区、后代媒体总览、来源路径、非媒体计数、虚拟网格/列表 |
| FR-03 浏览与查看 | 多选/快照全选、导航历史、同级路径、图片缩放旋转、视频播放/倍速/续播/全屏、重启恢复浏览上下文 |
| FR-04 查询与组织 | 参数化 SQL、FTS5 与短中文回退、维度组合筛选、自然排序、标签/收藏、不可变结果快照 |
| FR-05 封面 | 本地非 AI 推荐、实际 PTS 选帧、VFR/B 帧步进、16:10 裁剪、内容寻址原始快照、手动锁定、来源不可用仍可再次裁剪 |
| FR-06 文件操作 | 影响预览、源身份/版本复核、禁止覆盖、整目录移动、跨卷 SHA-256 双重校验、源句柄保留、系统回收站、操作日志与启动恢复 |
| FR-07 插件 | Cordis 适配层、内置导航/布局独立切换、JSON Schema 配置校验、依赖检查、启动回滚、基础导航/列表回退、可信本地开发插件入口 |
| FR-08 管理迁移 | SQLite 在线备份快照、校验管理包、封面对象流式读写、独立库导入、重复导入选择、根目录身份/指纹重绑、缓存与手动对象分离 |

安全边界：渲染进程开启沙箱与 contextIsolation，关闭 Node 集成；固定 preload 方法、来源验证、Zod 输入校验；媒体使用不透明授权令牌和 Range 流；FFmpeg 使用本地文件句柄自定义 AVIO 并拒绝嵌套资源打开。运行中不调用 AI 服务，不上传媒体，不执行在线遥测。

## 实测性能及口径

本机为 Intel Core i9-13900HX、16 GB 内存、Windows 11 x64；并非 PRD 指定的 6 核 12 线程标准机器。以下是实际结果，不替代完整 P0 性能验收。

| 指标 | 本机记录 | 测量范围 |
| --- | --- | --- |
| 十万文件基础索引 | 169.381 / 169.258 / 174.127 秒 | 3 个独立库；100,000 个零字节发现样本，10,100 个目录；不包含完整解码 |
| 新目录首批 50 项 | 355 / 333 / 347 ms | 从添加目录到后台报告已处理至少 50 项，含 IPC 轮询误差 |
| 启动到受限桥接就绪 | 1,145 / 1,150 / 1,184 ms | 不等同于上次大目录首屏全部可交互的 P95 |
| 十万条短中文查询 | IPC P95 498 / 515 / 493 ms | 每轮 30 次，查询物化和首批 100 条返回；不含完整 UI 提交时间 |
| SQLite 纯查询 | 中文全量 P95 213.01 ms；后代按时间 P95 252.93 ms | 每种 30 次热查询；查询服务内计时 |
| 1080p H.264 实际选帧 | P50 191.8 ms；P95 318.4 ms；最大 324.5 ms | 30 次，原生 seek/解码/PNG 与 Sharp 归一化；不含 UI 绘制 |

规模文件用于基础索引，不伪装成 100,000 个真实可解码媒体。媒体回归使用生成的 JPEG/PNG/WebP/GIF/BMP、H.264/AAC、VP8/Vorbis、VP9/Opus、VFR/B 帧及损坏样本；另有 1080p 样本。

复现命令：`node scripts/desktop-benchmark.mjs`；`npx vitest run tests/performance.test.ts`；`npx vitest run tests/media-benchmark.test.ts`。跨卷测试：设置 `VM_CROSS_VOLUME_ROOT` 为另一卷的专用测试目录，再运行 `node scripts/cross-volume.mjs`。脚本会创建隔离文件夹。

## 发布前仍需完成的验收与限制

- 尚未完成 PRD 要求的至少 200 个真实媒体样本、标准 6 核机器冷/热 UI P95、滚动长任务、5 分钟全进程 CPU/内存、长时间压力、150%/200% DPI、移动盘断连、全阶段崩溃注入、升级/降级矩阵。不能将本机冒烟与自动化结果称为全部 AC-01～AC-16 正式验收通过。
- 当前为首个数据结构版本；拒绝更高版本数据库/管理包。尚无可验证的历史版本升级链。后续结构升级必须补上升级前备份、失败恢复与旧版本样本测试。
- FFmpeg 动态库来自固定摘要的 LGPL shared 构建。应用的输入通道禁止网络与嵌套输入，但上游构建本身仍包含网络协议能力，尚不是 TRD 所要求的专门关闭网络组件的自构建发行物。公开发布前需要归档对应源码/构建脚本与全部第三方许可，并完成该原生发行构建和签名。
- 内置插件功能已经连通。开发模式当前提供可信宿主模块和槽位注册，尚未交付任意第三方自定义 React UI 模块的完整挂载协议、插件卸载管理或插件市场；开发插件不能被视为不可信代码沙箱。
- 管理包封面对象采用流式处理；索引 JSONL 解析仍在受限内存预算内完成（记录合计 256 MB、单成员 256 MB、解压总量 2 GB）。超限明确拒绝，超大管理包的全程增量记录导入仍需后续扩展。
- 不确定的崩溃恢复项会保留文件与日志并在任务中心提示人工核对；不是所有故障阶段都有一键重试入口。跨卷链接、备用数据流、加密文件等不安全情况会拒绝或保留源，不宣称完整支持 NTFS 所有特殊属性。
- 安装包未签名，未使用代码签名证书。首版提供真实可用功能及可复核测试，不应在未补齐上述条件时标记为正式 P0 发布认证。

依赖精确版本记录于 `package.json`、两个锁文件及 `native/dependencies.json`；发行校验值生成到 `release/artifacts.json` 和 `release/SHA256SUMS.txt`。
